# T80: the end state sealed (#291)

[derived: T80a-T80c, PRs #625, #626, #627; 2026-10-30] The plain Python port plays every admitted match
equal to the original with neither Unicorn nor any byte of GOAL.EXE at run time beyond its constant tables.

## What is sealed
- **The tables** (T80a, `static/goal-exe/tables/`, `tools/static/port_tables.py`): the initialised data
  segment DS:0000..7B6F and the listing's 173 code-segment data areas (11,572 bytes). The manifest holds
  positions and digests only; `port_tables.py extract --exe GOAL.EXE` builds the tables from the player's own
  file and refuses any other build ([designed: owner, 2026-10-29]: goal2 generates them, never ships them).
- **The input contract** (T80b, `out/T80/b/inputs-v1.md`): goal2's state = the memory with GOAL.EXE's load
  module left out, plus the initialised bytes the game changed (26 in the family's sources, the RNG word
  DS:7B62 among them). Probe v5: 75 of 75 identical from tables + state.
- **The engine without an image** (T80b): `port/tables.py`, `Image.state_of`/`Image.from_state`,
  `Match.records_after()`; `tests/test_port_seal.py`: the kit's check (engine, interactive, goals, knockout,
  family; no screen) PASSes every step in a child where `import unicorn` fails and opening .sav/.EXE/.DAT
  raises (PyPy: 2,634 s).
- **The whole family from records** (T80c): `family.py --from-records`; `compare.py --family ALL --no-screen`
  on `out/T80/c/sealed.jsonl` → 75 of 75 identical; A700 699 of 699 against T79's oracle (ref-121 not
  completed in either arm, #623).

## What is not sealed
- **The tournament continuation** (request 427, #427): what runs between matches (the competition's
  progress, the menus outside a match) is still the original's game under Unicorn in goal2; T80 seals the
  match and its post-match update only.
- **The board screen**: the port's full-time board screen is not the original's bytes (T78d, a known
  difference); every comparison here is without it.
- **The starting state**: a state is made from a memory goal2 already holds (a savestate of the original);
  making a fresh career's first state without one is not part of T80.
- **Speed**: PyPy 3.11 plays a match in about 50-60 s of CPU unloaded (CPython about 4x that); the runtime
  goal2 adopts is PyPy (#620).
