# T78a: plain-memory port dispatch

This slice supplies execution machinery for the existing translated routines.
It does not construct a complete Match, seal original data, or switch goal2's backend.

The existing `machine.py` handler/port/return ordering and `port/guest.py` PortFrame
protocol are the source. The plain backend retains near/far argument order, caller
cleanup, partial registers and pre-write listener semantics, and refuses addresses
without a registered routine or valid pending return. It never fetches an opcode.
The optional import in machine.py may fail; the new backend constructs no Unicorn
object and exposes no raw emulator. Registry installation chooses its explicit
port-memory factory; the original/proof read path is unchanged.

All tests here use synthetic zero memory and synthetic registered routines.
`out/T78a/register-controls-v1.json` is an independent reference-API flag control,
not a match or original-game experiment. `tests-before-v1.log` records the absent
engine module. `tests-after-v1.log` retains an intermediate test error: the new
synthetic generator used the obsolete docstring's mem.call notation instead of
the actual guest.call API. The test was corrected without changing assertions;
`tests-after-v2.log` records eight passing controls. Later receipts are additive.

The positive denial subprocess blocks Unicorn imports before loading the package,
checks that the denial actually fires, then executes a synthetic port successfully.
Corpus equivalence, real Match events and checkpoints belong to T78b–T78d.
