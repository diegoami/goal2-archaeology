# T78b3b logarithm, exponential and polynomial layer

Static first: named seg_23E4_02.c0E67/0F10/10E8/1101 and0CDF, followed by raw
seg_23E4_02.asm0E67–0F82,0CDF–0CE8 and10E8–114F. The raw111F–112E bytes are
marked db although LOOP1140 targets111F. out/T78b3b/decode_loop.py decodes that
existing source listing with the installed Capstone; loop-decode-v1.txt records
the pushes, three coefficient loads and near add call returning to112F.

The implementation directly translates normalization, the saved flags/sign,
integer/fraction splitting, source polynomial evaluation, exponent scaling and
reciprocal. All arithmetic reuses the proved T78b3a integer cores. Coefficients
are read through the source CS table addresses; this task does not embed them or
claim an image-free input API. T80 owns the later derived extract. There is no
host math.log/math.exp, opcode interpretation, original instruction fallback,
sound-flag change, fixture edit or new DS mask.

Synthetic differentials compare every final register/flag and SHA256 of full
guest memory including dead frames with unhooked original routines. Far-entry
controls cover zero/noncanonical zero, both signs, seeded mantissas (seed7832),
exponent limits,87/88/89 inputs and adjacent values around ln's103 exponent
cutoff; incoming flags202/ED7 cover preserved DF/IF and PUSHF. Original domain and
overflow errors207/205 are caught before00D1 and explicitly refused with matching
pre-handler state; only CS:IP are excluded for errors, as in T78b3a.

The two polynomial cores have separate near-ABI controls on authored coefficient
tables, counts1/2/6/8 and positive/zero/negative inputs; all memory/frame effects
are compared. The internal count0 path is not claimed as a supported caller:
ln and exp call with6 and8. No unvisited public menu route is claimed supported.
The positive-denial child installs the guard before kit import, then executes
ln1=0, exp0=1 and an authored polynomial1+2+2²=7 on PortMachine without a native
object. At this stage it still loads the hash-verified reference data image;
only T80 will prove refusal of original image files at runtime.

Immutable receipts: before-v1.log fails before this layer (132 failures and206
missing-entry/helper errors); transcendentals-v1/v2.log record the original
differentials before/after edge/hand-polynomial expansion. The final matrix has
352 far-entry and32 polynomial comparisons (384), plus the guarded controls.
regression-v1.log is the combined final arithmetic/helper/dispatcher/guest/runtime
suite. No original asset bytes are written by these controls; synthetic tables
are authored test values, and the decoder reads the already-published listing.
This layer is not full Match/corpus/checkpoint/sealed-delivery or goal2 adoption.
