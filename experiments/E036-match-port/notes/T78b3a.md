# T78b3a reached six-byte Real arithmetic

[derived] The unchanged admitted S/quick-1 scenario reaches the sound note's
23E4:0CB9 call with speaker enabled (T78b interface-v2.log). This makes its
arithmetic a real assembly prerequisite, not an optional hypothetical route.

Static first: read named seg_23E4_02.c at098F/0A52/0B57/0BF8/0C37 and checked
wrappers0C93/0CA5/0CAB/0CB9/0CC5, then raw seg_23E4_01.asm098F–0A4F and
seg_23E4_02.asm0A52–0CDC. The named view loses carry/register details; the raw
listing defines the actual algorithm, register widths and every stack write.
Real uses AL exponent and AH/BX/DX fraction/sign, not an IEEE host double.

Implementation is explicit Python integer translation, with structured loops for
alignment, normalization, partial products and long division. It reads no opcode
stream, executes no original instruction and uses no host float, native fallback,
sound-flag change or DS-mask change. RealRegs supplies local width/flag/stack
operations, as existing ports use Regs; it is not a guest instruction dispatcher.

Independent synthetic differentials initialize identical registers and memory in
an unmodified original machine and PortMachine. Compare all final registers and
flags and the SHA256 of every guest byte including dead frames. Inputs cover
zero/noncanonical zero, signed32-bit inputs, fractional operands, exponent
alignment39/40, cancellation, normalization, rounding/conversion boundaries,
overflow/underflow, both signs and seeded random mantissas (seed783); incoming
flags202/ED7 also exercise preserved DF/IF. Original code is the independent
oracle, not a second invocation of the new implementation.

Original errors are caught at23E4:00D1 before its DOS handler executes. The port
preserves the pre-handler registers/flags/memory, puts the same error code in AX,
and explicitly raises PortError. CS:IP differ by design at this refused boundary
and are excluded only for error controls; all valid controls compare them too.
Codes200 (division by zero),205 (overflow),207 (conversion/domain) must all be
visited. No error is silently converted into zero or an instruction fallback.

The guard child proves imports of Unicorn fail before importing the kit, executes
all five entries on zero-backed PortMachine and checks hand-derived1+1,1*2,1/2,
integer1 and negative-half rounding values. No original image is needed there.

Immutable receipts: before-v1.log fails before registration (initial900-case
matrix); arithmetic-v1.log passes that matrix; arithmetic-v2.log expands the
matrix; regression-v1.log adds noncanonical zero and existing controls;
regression-v2.log additionally requires all three error-code branches and the
negative-half hand-derived check. Original assets are fetched/verified by hash;
no original bytes are written to the tree. This is the arithmetic layer only,
not ln/exp, complete Match, strict corpus, sealing or goal2 adoption.
