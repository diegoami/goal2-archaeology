# T74: manager decision menus and a computer-only fixture

## Static method

Read the named bodies for the 27 T74 entries, then their raw instruction listings
and the existing kit key-entry hooks before implementation. The listing map is
`out/T74/static-inventory-1.json`. The key services are already semantic boundaries:
the unhooked kit returns directly at 214B:0723 and 08DD rather than running BIOS
interrupts; the port must preserve that boundary and its original pushed-back-key
exception. Other menu bodies retain their listing frames and guest calls.

## Computer-only fixture

An explicit managed country outside the fixture preserves the manager's identity
and leaves both participants' computer manager bytes unchanged. No sentinel or
implicit managed=None change is introduced. No human captain prompt exists;
recording starts at the existing play_match entry hook for this case only. Optional
seed/delay inputs are applied there, after setup. The new S scenario uses null
inputs and the existing human country7 with fixture1 versus2, calendar21.
The unhooked reference is recorded before menus is installed. Existing reference
files remain immutable; new bound references extend them with the new record.
