# T72: fixture and manager-pool player updates

Issue #283, route C P5e. `runtime/original_match/port/update.py` translates the
row's twelve routines: 0791:B7FA, B6CC, B71C, BA4E, B27F, B364 and
1771:10E7, 3558, 3651, 5A38, 5A8F, 5C60.

## Method

Static first: the annotation rows and named routines were read, then each
complete instruction listing in `code/seg_0791_18.asm` (B27F, B364, B6CC,
B71C), `seg_0791_19.asm` (B7FA, BA4E), `seg_1771_02.asm` (10E7),
`seg_1771_05.asm` (3558, 3651), `seg_1771_08.asm` (5A38, 5A8F, 5C60).
The listing determines register operations, argument high bytes, stack words,
near/far call form, call return addresses and write instruction addresses.
Every callee remains a guest call, including calls between the new ports.

The existing models (`model/energy.py`, `confidence.py`, `morale.py`) were read
and compared with the listing. No disagreement was found for these routines;
the new code uses the listing directly and tests use the existing energy and
confidence models as additional comparison references. It does not silently
change the models or any finding. Runtime constants cite the listed routines
and instruction offsets; synthetic table values are test inputs.

B7FA asks whether either side is managed with the listing's short circuit.
For each side it derives the result-relative confidence delta; when neither
side is managed and the fixture is not kind 1 it adds that delta to the
country's manager record. Every nonzero squad word receives the status update.
The XI and substituted-off bench players gain a cap, receive recovery and
result confidence; substituted-off players then clear Pascal element 3 and
receive the ordered bench-confidence draws. Unused bench players receive the
ordered draw(2)-draw(4) confidence change before recovery. When neither side
is managed, bench positions return to club positions. A pushed squad memory
word leaves AX at 2*slot: it must not load the player word into AX, since AH
is preserved by a following `mov al, flag` for 3651. The big-player-word unit
case distinguishes those stack argument bytes.

BA4E visits all eighty pool indices, without inventing a zero-word filter.
Its 16-bit end bound (start+79) can wrap; a start above that wrapped bound
returns without a visit. It uses the same recovery route and draws
confidence changes in the order draw(4), draw(4); kind 0 skips the status
update. The independent fixture router decides whether B7FA is called.

3558 uses the age>peak+4 table index. Managed draw order is rand(B+1) then
rand(3B), computing B+second-first; unmanaged is B+rand(2B). Fitness is an
8-bit store before the signed upper clamp. Energy copies it before the lower
fitness clamp, so synthetic negative/zero rolled fitness can leave energy
nonpositive while fitness becomes 1. 3651 preserves the three ordered recovery
paths, the below 16 rest bonus, the signed lower clamp that bypasses the age
cap, the age>peak+3 cap, and the healing coin only when energy is nonpositive.
The clipping helpers wrap at 16 bits before signed comparisons. Fixture margins
interpret both score bytes as signed, and expectation division truncates toward
zero. Calls and their dead frame residue remain part of family acceptance.

No run was needed to choose the translation. Runs corroborate it and establish
reach, including the final-record/seed sensitivity required for falsifiers.

## Early actual-family falsifier checks

The three diagnostic stores were sampled before freezing runtime/tests.
`compare_samples.py` validates the declared spec, image, completion and mask
through `compare.check`; `sample-compare-1.txt` additionally checks the task's
post-update hazard, not just a board or result field.

- confidence-plus-one: B3AD stores clipped confidence+1; O8/c1-c2-friendly
  differs in after.ranges.records.
- rolled-energy-plus-one: 3635 stores rolled fitness+1 into energy; the same
  friendly differs in after.ranges.records.
- recovered-energy-plus-one: 3774 stores recovered fitness+1 into energy;
  O8/c30-c44-friendly, whose 3651 entry count is 100, differs in records.

In all three accepted samples after.seed is unchanged but after.ranges.records
changes, while score, ticks, the full draw transcript, events, board, templates
and decisions remain unchanged. The c1-c2 qualifier has no 3651 call, so its
recovered-energy variant is explicitly retained as an unreached control and
is not counted as an accepted falsifier. Default c1-c2 friendly/qualifier and
c30-c44 friendly samples are exact (`sample-compare-1.txt`,
`sample-compare-c30.txt`). Unhooked coverage, not zero interior block counts
inside replaced routines, establishes each mutation's original branch reach.
