# T60 (P1a): the runtime primitives and the geometry queries, ported

Issue #271, branch `task/T60-port-runtime-geometry`. 70 routines of the backlog's row T60: 38 of the runtime
(`port/runtime.py`: 22 of GOAL.EXE's own library `214B`, 16 of Turbo Pascal's System unit `23E4`) and 32 geometry queries of
`0791:261A-2F28` (`port/geometry.py`). This page holds no status.

## Decisions

- **Wrapping the proven models.** The row says "where a proven model exists, the port wraps it". The models in `runtime/model/`
  (`keeping.py`, `longs.py`, `draws.py`) are not a package and `draws.py` imports `recreate` at top level; the kit's ports are
  vendored with it, standard library only. So the ports are written from the listing again (each constant cites its line) and the
  models are the cross-check: the value models of 278A, 0279 and 0D56 agree with the ports in `tests` and in the fuzz.
- **Registers.** The proof compares AX and DX of every call and the pushed words a guest call hands the callee carry the high bytes
  AH left, so each routine is written in the registers (`Regs`: AX..ES, SP, BP, with `al`/`ah`) and a routine it calls near is the
  same function on the same registers. BX, CX, SI, DI, ES are set where the listing's values are cheap; the flags only where a caller
  reads them (23E4:072F) and DF (214B:003C leaves it set after a backward copy: no `cld` follows its `std`).
- **The stack is part of the result** (below).
- **Division by zero** (23E4:0294) ends the original with runtime error 200 (`02FB-02FF`); the port raises `PortError`.
- **Guest calls**: 1771:3A06 (278A) and 1771:3216 (2956) are T61's, 0791:9079 (26C2) and the emitter 0791:1EB5 (2AA3, 2AD4, 2B0F,
  2B28; T69) are not ported yet: `yield call(...)` from the frame the listing has, so the stack the callee sees is the original's.
  A call between two ports of this task is a Python call on the same registers (its frame written by `invoke`); 278A and 287C
  call each other's entry through the machine because 278A calls the original's 3A06.

## The stack (found by the first family run)

The first ports passed every unit test and the fuzz, yet `S/quick-30` and `S/qualifier-21` differed from the reference in one
block of the after-match digests: DS+0xE400. `out/T60/memdiff.py` (the match run twice, the memory compared byte by byte) showed 102 bytes
differ, all in the stack segment 0x3A67-0x3D1A from its base: the unhooked match had return addresses, far-pointer segments (SS, DS)
and saved BPs there, the ported one older string text. The digests (`records.py`) cover the 64 KiB from DS, which includes the stack,
so the bytes a frame leaves below SP are part of what a ported match must equal, and the proof leaves them out (its dead frame).
T58's notes said no step compares them: true of the pilot (its frames were overwritten later by deeper calls), not in general.
Every port now writes the frame the listing's code writes. The fuzz (`out/T60/fuzz.py`) pre-fills the stack with random bytes and
compares the whole memory after the call, so a missing or extra stack write shows; with it every port equals the original.
The frames of 23E4:0787 and 07DB (two 256-byte temporaries each; no match of ALL reaches them) are written as they end, not
instruction by instruction.

## How exactness was checked

1. `fuzz.py --module runtime|geometry`: for each port, random inputs valid for the routine and its edges (equal bounds, a zero count, an
   offset at the top of a segment, overlapping strings, a screen stream with attribute prefixes and runs, a random match state in
   DS), the same memory and registers given to two machines, one running the original from the routine's entry to its return, the
   other the port. Compared: AX, DX, BP, SP, DS, SS, CS:IP, the direction flag, every byte of memory (the dead frame included);
   BX, CX, SI, DI, ES are counted as scratch, as the proof does. The original's bytes are read from the image at run time
   (`.cache/dl`, hash-checked): nothing of them is in the tree.
2. `variant_controls.py`: each falsifier run through the fuzz differs from the original (so the fuzz can see a wrong port).
3. The family runs and the proof (below).
