# T71: run_match and its post-match tail

Issue #282; route C P5d. The twelve routines of row T71 are translated in
`runtime/original_match/port/postmatch.py`: 0791:F1F6, CAB0, CB7D, BC5D, D050,
D016, D032, E929 and 1771:8757, 82BD, 85F7, 59D8.

## Method

Static first: read the named routines in `named/seg_0791_10.c` through
`seg_0791_13.c`, `named/seg_1771_04.c` and `seg_1771_06.c`, then the complete
instruction listings in `code/seg_0791_19.asm` (BC5D), `seg_0791_20.asm`
(CAB0/CB7D), `seg_0791_21.asm` (D016/D032/D050), `seg_0791_23.asm`
(E929/F1F6), `seg_1771_08.asm` (59D8), and `seg_1771_12.asm` (82BD/85F7/8757).
The listing determines argument words, register high bytes, local-frame bytes,
call return addresses and call near/far forms. No run was needed to choose the
translation; runs corroborate it and measure branch reach.

Each listing call stays a guest call, including calls between T71 routines.
The Pascal nested streak helpers receive D050's static-link BP word; the first
argument in [bp+6] is the home/away index, not the static link. D016 increments
+3+place and +5, D032 clears those bytes. D050 also updates season W/D/L and goals,
keeps best win/loss fixture records by absolute margin (ties replace), and
updates four home/away/all streak maxima. It asks the existing host and neutral
helpers through their guest calls. The annotation names for D016/D032/D050/E929
remain `likely`: this task adds no new finding id.

F1F6 fires the kit's F2E3 MATCH_PLAYED hook immediately after its F098 call and
before restoring the picture or scanning the man of the match. The three
4000-byte picture copies stay engine state. Snapshotting and the offer to save
are conditional on not being quick; the summary drawing and table update are
unconditional, as the listing says. The final team loop resets tactics only for
unmanaged teams and updates pool state only for managed teams. The final game
record +1 is set to 1. CAB0 uses signed performance, skips 0x7FFF, subtracts
10000 above 5000 and keeps the first tied best. CB7D restores morale for nonzero
squad words and fitness to energy only when signed energy is positive.

## Reach and tests

`out/T71/coverage_addresses.py` enumerates all twelve entries, every branch
target and conditional fall-through: 228 addresses. The unhooked ALL run is
`out/T71/coverage-unported-desktop-20261023/coverage-unported.jsonl`: 62/62
identical to T57. `coverage-summary.tsv` records counts and family reach;
205/228 addresses are reached, 23 are not. `unreached-block-tests.tsv` maps
every unreached address to a synthetic test and its reached boundary twin.

Two blocks cannot execute for the listing's own inputs: 1771:8489 (the sort's
first index runs 1..3, so first+1 never exceeds 4) and 1771:8714 (after 870A
falls through with second_home < first_home, 8712 would require equality).
The tests exercise both sides of the relevant comparisons; no test is claimed
to execute an impossible block. 870C is reachable when second_home < first_home.

`tests/test_port_postmatch.py` has eighteen tests, parametrized over quick versus
watched, save yes/no, friendly versus qualifier, managed versus unmanaged;
encoded/sentinel/tied performance and substituted-off bench players; zero,
positive and signed-negative energy; all twenty cleared tactics and eleven
restored positions; country W/D/L/streak/maxima and best results; group-stage
dimensions including empty bounds, fixture rejection, outcomes and three sort
tie breakers; aggregate exhausted/unplayed pairs, total-goals and away-goal ties.

`out/T71/test_controls.py` obtains runtime from the fixed pre-task commit
`a1f8a97dfd6593b8c88053083d1f33c113dff25b`, copies the current test module, and
runs once without postmatch plus 26 one-line mutations on top of that baseline.
All 27 controls are caught on the final source (`test-controls-6.txt`); earlier
24/25/26-control runs are retained (`test-controls-2.txt` through `test-controls-5.txt`). The first log is retained:
the missing-hook mutation initially raised ValueError from trace.index; adding
an explicit assertIn makes the missing behavior fail as an assertion.

ALL does not call 85F7 at all. `aggregate_differential.py` runs that actual
original routine and its port on fifty deterministic synthetic leg pairs from
the same verified image, with random stack bytes. AX/DX and every guest-memory
byte, the dead stack frame included, match in all fifty (`aggregate-differential-2.txt` on the final source; the initial
`aggregate-differential-1.txt` is retained).
This supplements the unit tests; it does not claim ALL covers 85F7.

An audit caught the predicate 59D8 using `_end(r, r.ax)` where the second
argument means “return AX”. That returned None when AX was zero, although the
machine already held the correct AX. Commit 656f654 returns `_end(r, value=True)`;
the predicate test now checks both zero and nonzero high bytes, and a control
mutating that correction back is caught. Earlier full-family outputs are retained
as intermediate evidence; the acceptance runs are repeated on the corrected source.

The initial man-tie-replaces and restore-energy-omitted falsifiers did not
produce a difference on the initial O8 sample; their immutable outputs remain.
The stronger controls added in b5b5db5 are man-best-reversed (the signed CB4E
comparison greater becomes less) and winner-count-two (D0AE increments a winning
country season win count by two). Both have direct synthetic tests alongside
their default-behavior twins. The group-points-one falsifier changes 83FF from
shifting the win bit left once to leaving it unshifted: it catches the O8
c1-c2 qualifier but not S/qualifier-21, whose 1-1 draw has no win bit. Commit
797f60e therefore adds group-points-bonus: 8401 adds one to the computed
points, affecting draws too. Its synthetic 1-1 twin checks the unchanged default
W0 D1 L0 GF1 GA1 P1 and the mutated W1 D0 L0 GF1 GA1 P2. The main session
records the full selected-match results and reach on the PR.
