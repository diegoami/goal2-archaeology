# T77: quick results and rare match branches

## Static method and translation

Read the named bodies and their callers, then the raw listings of all 17 row
routines. The immutable listing inventory is
[out/T77/listing-inventory-1.json](../out/T77/listing-inventory-1.json).
The raw instructions decide each operation, signed comparison, argument word,
stack frame and guest return site. The generated functions contain fixed Python
basic blocks, with original PCs beside the effects; they import no listing,
opcode table or original instruction bytes at runtime. The committed generator
and source map make the translation reproducible. Of 1,910 source instructions,
1,883 remain individually mapped and 27 immediate `push cs` instructions are
folded into the existing far guest-call mechanism. Every consumed argument is
still written at its original stack address. Calls remain T59 guest calls.
The generator is a build-time research artifact, not a new runtime mechanism.

The quick engine preserves its trial-score boundary: D77B clears the saved
committed score, B261 and D8A5 change trial counts, and DA58 alone writes the
committed result. At most one goal is committed in a call. It retains the
opponent-first signed contests, both teams' minute draws, unavailable-scorer
rerolls, tactic-dependent statistics, signed energy decrement, competitive foul
path and substitutions. Concrete units check the original memory writers,
strict equal-draw refusal, energy 0/1/2/127/255 and the one-goal limit.

scans squad slots 2..11 and changes the first available player's position to 0 at

concrete listing-value unit tests, and changing the stored role is caught by the
keeper-role mutation. The assumption is that the listing's fallback handles a
real computer goalkeeper loss with these effects. No original start state here
has corroborated that entry, and it is never claimed exact or impossible.
