# T78b1 residual helper ABIs

[derived] T78b's first genuine standalone match refused 23E4:08DF. The seven
literal guest-call targets absent from the registry have existing inline semantics
in pilot.py, but need the original calling convention when called independently.

Static reading preceded implementation: named 0791:045D,2974,2BE5,2DCA,
214B:0688,06B1,06FA and 23E4:08DF; raw matching listings establish exact
prologues, local writes, nested return addresses and returns. 08DF's result is ZF,
not AX. 2BE5 retains its nested 2974 frame. 06B1/06FA reuse pilot.rand's seed
step/writer, with source-backed 0688 register and frame effects added locally.
There is no separately registered 0688 entry (the earlier assembly summary was
incorrect on that detail); it is inlined into these wrappers, as in existing ports.

Synthetic controls compare all final registers/flags and every byte of guest
memory, including dead frames, against unhooked original routines. Cases cover
keeper word widths, side boundaries, half/left signedness, pitch signed-byte
bounds, set membership on/off including bit127/128/255 and high argument bytes,
RNG seeds/bounds including zero and 65535, both DF states and nonzero incoming
arithmetic flags. RNG write value and writer PC are independently compared.
The guard subprocess first proves Unicorn imports fail, then executes every
synthetic helper case on PortMachine without a native object.
