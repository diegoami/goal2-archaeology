## How goal2 uses it
1. Once, from the player's GOAL.EXE: `extract` → a tables folder in the user's data (refused unless the
   build is the registered one, set goal2-a949da2f), holding `ds.hex`, `code_data.hex` and a copy of the
   manifest, the folder `tables.load` reads (#631).
2. A match: `state = Image.from_memory_component(mem).state(tables)`;
   `Match(Image.from_state(state, tables), fixture, managed=..., engine="port")`; afterwards
   `m.records_after()` is goal2's next state.
3. Under PyPy 3.11 (#620): about 50-60 s of CPU a match.
4. The check from a state: `python3 -m ...original_match.check --engine port --no-unicorn --state S --tables D`.
