- **Why**: if a quick result is the same engine, the original can be sampled cheaply for G-M4's
  distributions and G-M5's checks; if not, every statistical claim needs watched matches.
- **Evidence** (pasted):
  - `docs/backlog.md` Q002: *From the same seeded start state, the quick result and the watched match
    give the same score and events; or, if not, their goal and booking distributions differ at
    n = 200 each.* `GOAL.HLP` 127 (a "quick result option"), Q09.7 (R computes the result; goals,
    bookings, sendings off and injuries listed in the commentary).
  - F004 (T08): the RNG `214B:0688` is seeded from the DOS hour and minute when a new game starts;
    the DOS year is a second input; a match runs live from the Enter that starts it and keeps drawing,
    and the in-match key poll `0791:9372` acts on `r` at its next poll, so sending Enter and `r`
    together replays identically (6 of 6). The driver sets and verifies the DOS date and time
    (`--dos-time`, `--dos-date` MM/DD/YYYY, I3) and refuses start states with another drive layout.
  - Static (T04 map, T06 backlog): `0791:A4A1` is the per-match set-up (F005; corrected by #30); its callers are
    `0791:BB2F`, `0791:E80D`, `0791:F1F6`; the commentary builder is `0791:1829`; the match state
    is `DS:80E8..8337` and `DS:7B7E..7C3E`.
  - F001: at `cycles=max` a watched match takes about 9.4 s from kick-off to full time.
- **Owns**: `experiments/E004-*/**`, `runs/E004/**`, `findings/F005-*`, `runtime/README.md`, `runtime/driver/**`

  the original (or the claim that it cannot). Behavioural: from seeded start states, play the same

  any rule of the engine itself.

     the commentary, and `DS:7B62` at full time, and whether the pair is identical.
