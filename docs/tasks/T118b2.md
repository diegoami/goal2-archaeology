- **Scope**: protects two things a port of the news needs.
  - **Draws:** every RNG step of the text routines, with the condition under which it is reached and its count per
    call (loops named), so a port draws the same numbers in the same order.
  - **No other state:** every write is to the frame, a screen buffer, or a DS byte used only for display. Any other
    write is a row with its target, found by reading it, never assumed.
  - **Texts:** named by their DS or CS address and the values that fill them, with no text copied beyond
    identifiers. The key waits (`05F6` and its family) are listed: goal2 shows a page at each.
  - **Out of scope:** the port, and runs.
