  - F004: the RNG `214B:0688` is seeded from the DOS hour:minute at a new game (`DS:7B62`); the
    moment a key reaches the live match changes it, and Enter and `r` sent together replay
    identically. `214B:1DA7` counts loop passes during one BIOS tick, divides by 55 and stores the
    count at `DS:A9FF` (`seg_214B_04.asm:44`–`69`); `214B:1E09` (`:75`) busy-waits that count per
    millisecond. Both are in guest memory, so a savestate holds the calibration made when the game
    started.
  - F005 (T10): the tick loop `0791:97D0` calls the watched engine `0791:9564`, or `0791:D733` under
    the quick flag `DS:9A3E`; the clock `0791:970C` counts `DS:831D` down from 0x24 per game minute.
    `1E09` is reachable from all of them (`97D0 → 970C → 0425 → 1E09`, `9564 → 94E8 → 0425 → 1E09`,
    `D733 → 8062 → 7FCF → CC2E → 1E09`). `1DA7` and the seed `0791:F3F2` are start-up code with no
    path from the match. The tick read in `214B:0D90` (via the line editor `214B:1086`) is an open
    candidate. Under E004's conditions (`cycles=30000`, keys only at the half-time screens) 16 watched
    replays and 3 fresh-launch repeats were identical to their first.
