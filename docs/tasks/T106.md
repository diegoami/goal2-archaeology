- **Kind**: bounded measurement; planning brief under [programme #433](https://github.com/diegoami/goal2-archaeology/issues/433).
- **Issue**: [#445](https://github.com/diegoami/goal2-archaeology/issues/445); **Branch**: `task/T106-engine-study`; **Merge after**: T105; ES-R2 accepted.
- **Difficulty**: hard; **Size**: M (2–4 active hours, compute separate); **Complexity**: medium; **Impact**: high.
- **Rating rationale**: The measurement is local, lowering coupling; original/port agreement and independent expectations still demand hard research.
- **Implementer**: main session, `gpt-6.1-sol` at `high`; perform the task directly.
- **Targeted help**: sparingly spawn a `gpt-6.1-sol` / `xhigh` agent only for the hardest bounded subproblem; no automatic task delegation.
- **Reviewer**: independent Claude or Kimi at the existing checkpoint; never an author of the deliverables.
- **Review checkpoint**: [ES-R3](../engine-study-reviews.md#es-r3); exact entry, scope and exit criteria apply.
- **Evidence**: T105 approved probe specifications, existing E028 probes and original-match instrumentation.
- **Owns**: `docs/engine-study/micro-probes.md`, `notes/engine-study/T106/` (probe or batch scripts and immutable outputs). The executable slice fixes exact source/annotation ownership before dispatch.
- **Scope**: Implement only the selected cheap routine/short-scenario probes, reusing existing tooling. Validate literal predictions, thresholds, no-effect controls and selected interactions against the original and the port where supported. Preserve source hashes, fixture provenance and all raw receipts.
- **Acceptance outcomes**: Every executed probe has immutable inputs/outputs, return/completion checks, an independent expected result and a negative or mutation control. The report gives pass/disagreement/unresolved counts and distinguishes legal reachable fixtures from deliberately synthetic edges.
- **Dispatch gate / Done when**: this brief records scope and expected research results, not executable readiness. Split into independently mergeable, approximately one-hour slices before dispatch; each gets its own issue, ownership and contract. Validate each slice's Done-when commands as failing on pre-task main and passing on a mock fix. Require source/evidence checks, relevant controls and `python3 tools/check_links.py`; ordinary research outcomes above remain mandatory.
- **Hazards**: The same implementation cannot supply both expected and actual results. An artificial state establishes a mechanism at that state, not its frequency or natural reachability.

Apply the [main-session model policy](../engine-study-models.md) and [programme methods/gates](../engine-study-plan.md); slices inherit these assignments.
