- **Scope**:
  - **Protects:** evidence and citation integrity here. None of these may get through:
    - a check run with this repository's old copies, or with anything but game-archaeologist's files
      at the pinned commit;
    - a fetched file used without its blob sha matching the pinned tree;
    - a partly fetched cache, or one from another commit, used for this pin;
    - a wrapper that changes arguments, streams or the exit code;
    - a finding, record or evidence manifest changed to make a check pass;
    - a crash instead of a named error.
  - **Threat model** (the owner, 2026-10-05): guard against accidents (a partial or stale cache, a
    mistaken edit, a symlinked cache root, filesystem errors as named errors), not deliberate
    tampering during a run.
  - **`archaeology.json`:**
    - pin game-archaeologist at `c3a27a6` (the full sha; drop the `formats-v1` tag, which names an
      older commit);
    - add `tools/verify_evidence.py` and `tools/check_citations.py` to `uses`.
  - **`tools/ga.py`:**
    - Add both tools to `NEEDED_FILES`.
    - A cache missing any needed file is fetched again, never used.
    - Each fetched file's git blob sha is checked against the pinned tree before use; a mismatch is
      a named error.
    - The existing exposed names keep their signatures.
  - **`tools/verify_evidence.py` and `tools/check_citations.py`** become pass-through wrappers, as
    `tools/register_artifact.py` is: the pinned tool, the same arguments, streams and exit code, run
    from the working directory.
