- **Scope**: what this protects: a port replaces its routine at every call while every event, draw and decision the kit reports stays the original's.
  1. `Match(..., ports=...)`, and `check.py --ports` and `--variant`: a port runs in place of its routine from the entry and returns as the listing's `ret`/`retf n`. Ports are written against a memory view (`port.mem`) that works over the kit's machine now and over plain memory later (T78): reads; writes that reach the kit's watches as the original's would; the frame of a nested procedure; key reads answered by the kit's logic for the site; the kit's site hooks fired at the listing's point when the routine holding them is ported.
  2. Ports register themselves per module (no shared table), with named variants (falsifiers) and stubs (a routine replaced by a declared return value, for T73).
  3. The pilot moved in as `port/pilot.py`, its three falsifiers as variants.
  4. A saved match names its ports; the kit's `VERSION` changes if the save format does. With no ports the kit is unchanged.
- **Done when**:
  1. `PYTHONPATH=runtime python3 -B -m original_match.check --cache .cache/dl --family --ports pilot` → engine, interactive, goals, knockout and family PASS, the pilot's call counts printed (> 0).
  2. With `--variant pilot.coin-swapped`, `pilot.bound-36` and `pilot.no-picture` in turn, the family step FAILs: each changes or stops at least one of its ten seeds (printed per seed).
  3. Without ports, `check.py --family` passes as on `main`; `python3 -B -m unittest tests.test_port_mode` (a port's write fires the kit's watch; a site inside a ported routine fires; a stub returns its value; a replayed hook runs no port twice) fails on `main` and passes; the full suite passes.
- **Hazards**: a write that bypasses the memory view loses an event or a draw without an error; the replay rule above; nothing of the original in the kit folder (goal2 vendors it byte for byte: say in its README what ports change for goal2, which is nothing until it passes `ports`); Python with `-B`; never overwrite an output.
