# T05 The documentation map: GOAL.HLP passages as sources (G4)

- **Kind**: research (documentation)
- **Issue**: #6 · **Branch**: `task/T05-documentation-map` · **Merge after**: T01
- **Implementer**: the main session or a scoped helper using caller-configured model/settings; no fixed model or automatic per-task spawning. See [model policy](../model-policy.md).
- **Reviewer**: independent under the repository review rules; caller-configured model/settings, without a named-model requirement.
- **Why**: the help file is the only primary documentation of GOAL2. Recording its passages as cited
  sources moves each knowledge-map area from `unknown` to `documented`, and gives every later
  research question its stated expectation to test. `docs/plan.md` G4.
- **Evidence** (pasted):
  - `knowledge-map.md` (T01): 17 areas, all `unknown`, each with the `GOAL.HLP` lines that describe it.
  - `GOAL.HLP` (the release `goal2-original`): 702 lines of plain text with CR LF line ends, by New
    Era Software, distributed by Wizard Games of Scotland.
  - game-archaeologist `vocabulary/status.md`: `documented` means "asserted by a manual, help file or
    designer, and not yet tested", basis `doc`. A `doc` basis can only make a claim `documented`.
  - U17: GOAL2's files and extracts may sit in this private repository.
- **Owns**: `sources/**`, `knowledge-map.md`
- **Scope**:
  - `sources/goal-hlp.md`: the help file's passages that make a claim about the game, each quoted
    verbatim with its line numbers (CR stripped), grouped by knowledge-map area. A passage is quoted
    once and referenced from every area it informs. The file says which artifact and sha256 it
    quotes.
  - `knowledge-map.md`: each area whose passages make a testable statement moves to `documented`,
    with basis `doc` and links to its passages. The "what the bot needs" column is unchanged. An area
    with nothing testable stays `unknown`, and the row says why.
  - **Testable statements** are listed per area as candidate research questions (for G5), each
    worded as an observable prediction, without a judgment of whether it is true.
  - **Not in scope**: running the game, the executable, `spec/`, any claim beyond `documented`.
- **Done when**:
  1. Every quotation in `sources/goal-hlp.md` matches the released `GOAL.HLP` at its cited lines
     exactly (CR stripped): `python3 sources/check_quotes.py <path to GOAL.HLP>` checks them all and
     prints 0 mismatches; the reviewer re-runs it on the released file and checks three by hand.
  2. Every `documented` cell in `knowledge-map.md` links to at least one passage, and every area left
     `unknown` says why.
  3. No cell is above `documented`: `grep -ciE "supported|corroborated" knowledge-map.md` prints `0`.
  4. `python3 tools/check_links.py` exits 0, and CI is green.
- **Hazards**:
  - paraphrase in a quotation, or a quotation stretched beyond its lines;
  - judging a statement true or false: this task only records what the help file says;
  - moving an area to `documented` on marketing text that predicts nothing observable.
