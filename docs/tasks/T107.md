# T107 Run the first bounded match sensitivity batch (engine study)

- **Kind**: bounded measurement; planning brief under [programme #433](https://github.com/diegoami/goal2-archaeology/issues/433).
- **Issue**: [#446](https://github.com/diegoami/goal2-archaeology/issues/446); **Branch**: `task/T107-engine-study`; **Merge after**: T105, T106.
- **Difficulty**: hard; **Size**: M (2–4 active hours; compute separately capped); **Complexity**: high; **Impact**: medium.
- **Rating rationale**: Sampling, path divergence and context interactions make complexity high. Practical effect sizing is medium impact under the existing rubric.
- **Implementer**: main session or the session's selected implementer, using repository tools. **Reviewer**: independent strong-model review for new rule claims; milestone review in T113.
- **Evidence**: T105 preregistration, T106 controls, validated original/port execution path and T79 fidelity records when available.
- **Owns**: `docs/engine-study/match-effects.md`, `notes/engine-study/T107/` (probe or batch scripts and immutable outputs). The executable slice fixes exact source/annotation ownership before dispatch.
- **Scope**: Execute the first preregistered match batch on the validated path, with selected attribute/tactic contrasts, ordinary fixtures and declared context variation. Measure intermediate events as well as score, shots, possession, fouls, cards and energy. Publish results, including null or inconclusive effects, before considering more runs.
- **Acceptance outcomes**: The batch respects its pinned design, cap and completion checks. Reproducible summaries give N, effect sizes/intervals, seed/context structure, failures and exploratory versus confirmatory labels. Deviations and further batches become separately scoped follow-ups.
- **Dispatch gate / Done when**: this brief records scope and expected research results, not executable readiness. Split into independently mergeable, approximately one-hour slices before dispatch; each gets its own issue, ownership and contract. Validate each slice's Done-when commands as failing on pre-task main and passing on a mock fix. Require source/evidence checks, relevant controls and `python3 tools/check_links.py`; ordinary research outcomes above remain mandatory.
- **Hazards**: Do not launch a large sweep because the plan exists, substitute quick results for watched play, treat common seeds as independent evidence, or claim equivalence from an inconclusive test.

Use the [programme's methods, rating definitions and gates](../engine-study-plan.md).
New measurements have immutable source-pinned receipts; a budget is set before a heavy job.
This package does not select a production backend or silently repair original behaviour.
