- **Scope**:
  1. **R1 (stability-fallback re-stage).** The stability fallback in the recorder polls the live
     savestate's signature; when `_fast_consumed == (events, sig)` matches the current write's
     signature, it short-circuits, but the bytes it would re-stage belong to a request whose
     capture was already consumed under that pair. The Sol reproduction injects a clock so two
     requests share the same `(events, sig)` (`_submitted=2`, `_finished=0`); the fallback re-stages
     the live bytes under the earlier request. Fix: the fallback reads from the per-request path,
     not the live savestate; it re-stages from the live path only when the per-request path's
     bytes are missing/stale **and** the request's ownership is otherwise valid (the request's
     `pre_sig` differs from the current `sig` and the per-request `_fast_consumed` is from an
     earlier write).
  2. **R2 (evidence-free guard).** `check_attribution` allows a request whose `superseded` flag is
     absent to count as a successful request line. The Sol reproduction constructs a bracketing
     snapshot + key event whose staged bytes belong to a later request; with all four checks
     (attribution, burst count, request-window timing, mapped coverage) passing, the guard exits 0.
     Fix: `check_attribution` requires per-request path bytes or their hash to match the request's
     pre-send state (`pre_sig` AND a hash of the per-request path's bytes when those bytes
     exist), with no "absence of `superseded` is enough" fallback. Missing-staged requests fail;
     superseded requests fail; missing per-request path bytes fail unless R1's ownership ledger
     proves the bytes were valid under an earlier write that has since been consumed.
  3. The two Sol r4 reproductions, scripted in `mutate_keys.py`, must each exit 1 with a clear
     error after the fix; the existing reproductions (10/10 mapped at 0.51 s; 2 s sleep deferred
     capture) must still exit 0.
  4. Mutation sweep: 2 mutations per predicted bypass class (R1, R2); 0 survivors; the regressions
     must fail before the fix.
  5. CI green (`python3 -m unittest discover -s tests`, `discover -s tests/static`,
     `python3 tools/check_links.py`).
