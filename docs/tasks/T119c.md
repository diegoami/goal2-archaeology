# T119c The route harness plays managed competitive matches; its key policy names the table reads

- **Kind**: correction (of T119a, #647) · **Issue**: #647 · **Branch**: `task/T119c-route-competitive` ·
  **Merge after**: T119b
- **Implementer**: the main session (Track B, goal2 #509). **Review**: the milestone's (rule 4).
- **Evidence**: [confirmed: E040, T119b (#646)]
  - Every competitive fixture holds its round number in fixture byte +1 (1..8; 0 in friendlies).
  - `match.py` `_write_fixture` writes `FE 00 kind 00 …`. So `Route._match` refuses every managed non-friendly:
    "Match's set-up wrote what route_fixture had not left there".
  - E040-r0010 and r0011, the E015 qualifier, abort that way.
  - The silent path's `E929` reads keys at `214B:157C` from `1771:9022` and `91BE`, and at `1771:9567`. That is
    `Match`'s `TABLE_READS`, which `route.DEFAULT_KEYS` doesn't name.
- **Owns**:
  - `runtime/original_match/match.py`: only the route mode's fixture set-up, with default matches unchanged.
  - `runtime/original_match/route.py`: the default key policy.
  - `tests/test_route_harness.py`.
  - `experiments/E040-route-fixture-writes/` (new records `r0013+`, the coverage).
  - F039's corroboration section.
- **Scope**: protects the harness's faithfulness on competitive fixtures. It mustn't refuse them, and it mustn't
  let `Match` change them.
  - With `tail=False`, `Match` keeps what route_fixture left in the fixture record (+1, and +3 if route_fixture
    has set it). It writes only what it writes for a friendly today, and the harness's whole-memory check still
    holds.
  - The default policy answers the table reads with Enter, as `Match` does.
  - E040 is rerun on E015-r0007 state 213 and E015-r0009 state 3. It must cover the confidence term (`B71C`,
    `B6CC`) for both sides and a competitive result.
- **Done when**:
  1. `python3 -B -m unittest tests.test_route_harness -v` passes, with new cases that fail on `main`:
     - a managed qualifier from E015-r0009 state 3 plays through `Match(tail=False)` and resumes;
     - the table reads are in the default policy;
     - a default `Match` still writes its fixture as before.
  2. `python3 -B experiments/E040-route-fixture-writes/runner.py --check` passes. Its records now include a
     competitive managed fixture, whose confidence rows (`000E:6F80`, `6F86`) are visited for both sides.
  3. CI is green.
- **Hazards**: `_write_fixture` also serves goal2's own matches, so keep the default path byte for byte, and test
  it.
