# T95 Engine inventory and evidence map (engine study)

- **Kind**: research inventory; planning brief under [programme #433](https://github.com/diegoami/goal2-archaeology/issues/433).
- **Issue**: [#434](https://github.com/diegoami/goal2-archaeology/issues/434); **Branch**: `task/T95-engine-study`; **Merge after**: the planning PR.
- **Difficulty**: easy; **Size**: S (0.5–1 active hours, compute separate); **Complexity**: medium; **Impact**: high.
- **Rating rationale**: Indexing is straightforward; the breadth of entry paths makes coordination medium complexity. It unblocks every chapter.
- **Implementer**: main session or the session's selected implementer, using repository tools. **Reviewer**: an independent evidence/coverage check; milestone review in T113.
- **Evidence**: runtime/original_match/port/, its registry, F013, E036 coverage and the T57–T80 contracts.
- **Owns**: `docs/engine-study/inventory.md`, `notes/engine-study/T95/` (source census and supporting evidence). The executable slice fixes exact source/annotation ownership before dispatch.
- **Scope**: Count and map registered routines, modules, match paths and current evidence. Trace setup, tick, decisions, motion, contests, events and post-match updates; identify the readers' entry points and the untested frontier. Inventory the original sources, reviewed findings, tests and retained runs without promoting their evidence levels.
- **Acceptance outcomes**: The inventory accounts for every registered module and routine in a pinned checkout, assigns each to a chapter or an explicit unresolved bucket, and links every existing evidence family. Record counts and a list of gaps, including the separate watched, quick and unattended paths.
- **Dispatch gate / Done when**: this brief records scope and expected research results, not executable readiness. Pin the inventory and exact commands before marking ready. Validate each slice's Done-when commands as failing on pre-task main and passing on a mock fix. Require source/evidence checks, relevant controls and `python3 tools/check_links.py`; ordinary research outcomes above remain mandatory.
- **Hazards**: An old checkpoint or a translated routine is not proof of a completed standalone engine. Preserve exact source hashes and distinguish historical statements from current evidence.

Use the [programme's methods, rating definitions and gates](../engine-study-plan.md).
New measurements have immutable source-pinned receipts; a budget is set before a heavy job.
This package does not select a production backend or silently repair original behaviour.
