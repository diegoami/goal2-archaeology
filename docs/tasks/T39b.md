# T39b The coaching kit: a pause key, live view and notes in the recorder

- **Kind**: tool (the recorder, `runtime/human/`), with one short sitting by the owner as its test
- **Issue**: #138 · **Branch**: `task/T39b-coaching-kit` · **Merge after**: —
- **Implementer**: the owner's choice at dispatch · **Reviewer**: the owner's choice at review
- **Why**: the owner coaches the main session while playing (the owner, 2026-10-11): they play, type
  notes in the chat, and the main session watches the newest screen. Some screens move on before the
  owner can stop them, so a pause outside the game is needed.
- **Protects**: the record's integrity and the owner's privacy: a pause or a note never loses or
  invents a key or a snapshot, and nothing typed outside the game window is recorded (T34's proof).
- **Evidence** (pasted):
  - DOSBox-X 2024.03.01 has the mapper events `mapper_pause` ("Pause emulation") and
    `mapper_pauseints` (`strings` of `~/tools/dosbox-x-2024.03.01/usr/bin/dosbox-x`, 2026-10-11).
  - The recorder (`runtime/human/recorder.py`, `play.sh`) launches DOSBox-X with a per-session
    config whose `[sdl] mapperfile` points into the session folder (recorder.py:1269 and the
    sitting's `meta.json`), sends the host key F12+S directly to the game window every ~20 s and per
    key burst, and logs keys on the nested display only (T34).
  - #128: while a save is written, a new request supersedes it; T35's guard refuses to stage it.
- **Owns**: `runtime/human/**`, `tests/test_human_*.py`, `experiments/E015-human-playthrough/**`
  (new files, the protocol's notes on pausing, a test sitting's record), `runs/E015/**` and
  `evidence/E015/**` (new records only), `docs/recorder-architecture.md`.
- **Scope**:
  1. **Pause**: the session's mapper file binds `mapper_pause` to F12+P (or the nearest free host
     combination, saying why); the recorder logs each pause and resume with its time
     (`pauses.jsonl`), sends no save request while paused, and requests one snapshot right after
     the pause starts if the emulator allows it (else right after it ends, saying which); the key
     map treats a paused span as no time.
  2. **Live view**: `python3 runtime/human/live.py <session>` prints the newest staged snapshot's
     screen (CP437 text) and the keys since the previous call, read-only, while the sitting runs.
  3. **Notes**: `python3 runtime/human/note.py <session> "text"` appends a line to the session's
     `notes.jsonl` with the UTC time; `extract.py` carries the notes into the record, each placed
     between the snapshots it falls between.
  4. **The test sitting**: the owner plays 2–3 minutes with two pauses and two notes; it is
     extracted as a new E015 record.
  Not in scope: #128's save scheduling; the screen catalogue (T39a); the video (T39c).
- **Done when**:
  1. `python3 -m unittest -v tests.test_human_pause` (new): a pause mid-burst sends no save request
     while paused and loses no key; a paused span is excluded from the key map's quiet-gap rule;
     every test fails with its rule removed (the PR lists the mutations, in place).
  2. The test sitting's record shows the two pauses (start, end), the two notes in their places, the
     snapshot around each pause, and the same press count as `keys.jsonl`'s presses; `python3
     tools/validate_runs.py runs/E015` and `python3 tools/verify_evidence.py E015` pass.
  3. `live.py` on the running test sitting printed the newest screen at least twice (the PR shows
     the output) and wrote nothing into the session folder.
  4. `python3 -m unittest discover -s tests` passes (the recorder's existing tests unchanged in what
     they assert); `python3 tools/check_links.py` passes.
- **Hazards**:
  - the privacy proof (T34): pause and notes add no logger on the outer display; chat typing stays
    unrecorded;
  - a save requested while paused that lands after resume as if it were later play;
  - the owner's sitting is the only run: prepare everything so it takes one try; the DOSBox-X
    version is 2024.03.01 (`require_dosbox()`); never display `:99`;
  - push after each step; a draft PR after the first push.
