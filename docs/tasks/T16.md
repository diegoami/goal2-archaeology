- **Why**: F007 found that the 20-byte player record holds no twelve separate skills: it holds ages,
  a country ceiling (+3), a current value (+4), a position and a few draws. The rebuild needs to
  know what the player screen shows and how each shown value comes from the record (stored, derived,
  or held somewhere else). F007's inferred meanings (age about 75%, potential about 70%, current
  ability about 75%) are confirmed or refuted by the screen.
