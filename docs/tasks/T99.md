- **Kind**: analytical research; planning brief under [programme #433](https://github.com/diegoami/goal2-archaeology/issues/433).
- **Issue**: [#438](https://github.com/diegoami/goal2-archaeology/issues/438); **Branch**: `task/T99-engine-study`; **Merge after**: T98.

- **Implementer**: the main session or a scoped helper using caller-configured model/settings; no fixed model or automatic per-task spawning. See [model policy](../model-policy.md).
- **Targeted help**: use a scoped helper when useful, with caller-configured model/settings; no automatic model escalation.
- **Reviewer**: independent under the repository review rules; caller-configured model/settings, without a named-model requirement.
- **Review checkpoint**: [ES-R1](../engine-study-reviews.md#es-r1); exact entry, scope and exit criteria apply.
- **Evidence**: F022, contests.py, ball.py, duels.py, quick.py and the RNG runtime/listing.
- **Owns**: `docs/engine-study/contest-formulas.md`, `notes/engine-study/T99/` (source census and supporting evidence). The executable slice fixes exact source/annotation ownership before dispatch.
- **Scope**: Derive skill gates and opposing-player contest probabilities for passing, tackling, shooting, headers and saves. Explain random bounds, strict versus inclusive comparisons, stopping branches and deterministic selection ties. State assumptions behind probability formulas and distinguish them from the correlated finite RNG stream.
- **Acceptance outcomes**: Every contest family has its inputs, decision rule, source references and at least an ordinary and boundary worked example. Label unreachable or unmeasured paths and predictions that require targeted corroboration.
- **Dispatch / Done when**: implement [T99a](T99a.md) then [T99b](T99b.md), one branch/PR each. Both executable slice contracts and numerical/source controls must pass before this package closes; original acceptance outcomes remain mandatory. Owns additionally `docs/engine-study/skill-gates.md`; shared integrity checker: `notes/engine-study/foundations/check.py`.

- **Hazards**: Independent uniform draws are an analytical approximation unless justified. A success rate at one contest is not a match win rate or evidence of monotonic whole-match improvement.

Apply the [main-session model policy](../model-policy.md) and [programme methods/gates](../engine-study-plan.md); slices inherit these assignments.
