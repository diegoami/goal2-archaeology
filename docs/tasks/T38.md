# T38 M0: the emulator runs whole watched matches, with inputs and a substitution hook

- **Kind**: tool + check against records (milestone M0 of [plan.md](../plan.md), "The watched
  match: read it and run it")
- **Issue**: #135 · **Branch**: `task/T38-m0-whole-match-harness` · **Merge after**: —
- **Implementer**: the owner's choice at dispatch (CLAUDE.md "Choosing models" rule 1)
- **Reviewer**: the owner's choice at review (rule 2); never the implementer's family
- **Why**: every later milestone (M1–M6) learns the watched engine by replacing one routine of the
  original with its model and checking the match stays exact, and the bot's effect measurements run
  the original's code on chosen inputs. Today the harness can only play a second half from a
  half-time savestate, unchanged.
- **Protects**: the harness's exactness claim: a match it reports as reproduced is on the
  original's tick-exact trajectory, and a wrong substitution cannot pass as right.

  - E011 notes §5–§6: the half-time stall (`0791:9A32` → the wait `ED8A`, then `DS:830B`,

- **Scope**, in steps that each end in a pushed commit:
  1. **The entry.** Read where a watched match starts (`F1F6`/`A4A1`, the first half's `983F`) and
     choose the harness's start point and start state: a published savestate before the kick-off of
     an E011 ground-truth match if one exists; if not, stage one under `runs/E021/` (at most 2
     DOSBox-X runs), as E011 staged its stall. `notes.md` says which, with listing lines.
  2. **Whole matches.** The harness runs from that point to full time as guest code, through the
     half-time stall (the wait `ED8A` handled as E004's discipline makes the original handle it:
     say how, with listing lines), with the existing interventions only (interrupts swallowed, the
     key thunk "no key", the `000E` wait family skipped and logged, its log empty).
  3. **Inputs.** Before the match: the main seed word, a country's `+0x2D`, any player record's
     bytes, the squad order, each as a declared memory write (an I3 intervention), recorded with the
     run.
  4. **Outputs.** At full time: the score, the scorers and minutes, the commentary ring, the main
     seed's draws with the clock (as today), and the full-time statistics the screen shows (F014's
     fields where established; else the raw words, named as raw).
  5. **The substitution hook.** `hook(address, fn)`: when the guest calls the routine at
     `address`, `fn` runs instead on the emulated machine (it reads and writes registers and memory)
     and the guest returns as the routine would; every hooked call is counted. The proof uses
     `214B:0688` (F004's step) as its routine.
  Not in scope: modelling any match routine beyond the hook's proof (M1 onward); keys during play
  (the owner's sittings change tactics and players mid-match: a later milestone); the quick engine.
- **Done when**:
  1. `python3 experiments/E021-m0-whole-match/check.py` emulates each E011 ground-truth match from
     the chosen start to full time and prints `match: N/N` over every mid-play read of both halves
     (`(831F, 831D, 7B62)` on the emulated trajectory, F013's rule), with N the count of the
     records' reads and every read present, and the full-time score equal to the record's; it exits
     non-zero on an empty set or any miss, and the `000E` skip log is empty.
  2. The same check with `hook(214B:0688, <Python LCG of F004>)` prints the same `match: N/N` and a
     non-zero hooked-call count; with the hook's multiplier or increment changed by +1 (each, one at a
     time) it reports misses and exits non-zero. The PR shows the three runs' output lines.
  3. An input run: the same start with one country's `+0x2D` changed (a declared write) completes
     to full time, and its record shows the write, the score, and the first tick whose seed value
     leaves the unchanged run's trajectory (or "none", with why).
  4. `python3 -m unittest discover -s tests` and `discover -s tests/static` pass;
     `tests/test_emul_*.py` pin the hook (a hooked routine is not executed as guest code; the count
     is exact) with literal expected values; `python3 tools/check_links.py` passes; if runs were
     taken, `python3 tools/validate_runs.py runs/E021` and `python3 tools/verify_evidence.py E021`
     pass.
- **Hazards**:
  - a check that passes by skipping: every read of the records is a checkpoint, by its stored
    `(831F, 831D, 7B62)`, none excluded; an empty set fails;
  - a half-time handled by writing the second half's start state into memory: the first half's own
    end must flow into the second as guest code (only the wait itself is handled, as declared);
  - a hook that still runs the guest routine (then a wrong model cannot break the match): the test
    shows the routine's own code is not reached;
  - a stray RNG consumer missed by the interventions (E010's lesson): the `000E` skip log stays
    empty, and a non-empty log voids the run;
  - static first (CLAUDE.md rule 22): DOSBox-X runs only to stage a missing start state, at most 2,
    each recorded; the version is 2024.03.01 (the driver finds `~/tools/dosbox-x-2024.03.01`);
    never display `:99`; keep staged states, never delete them;
  - do NOT run Ghidra (OpenCode cannot reach it); this task needs no `named/` change;
  - long commands run detached with a log, polled in short calls; push after each step and at least
    every 20 minutes; open a draft PR after the first push.
