- **Why**: the rebuild's match engine and the bot's keeper selection both need the exact place
  keeping is read (a goalkeeper-only gate in the keeper special `0791:9636`–`9666`, F013) and the
  exact place a penalty is decided (`0791:A10A`, the shoot-out). The player record holds no twelve
  skills (F008): each is computed by `1771:3947` as
  `DS:6DCD[12 · (+5) + DS:6D25[12 · (+7) + i]] · ((+4) + 1) div 256`. The match engine may read
  that derivation or store a value of its own; F008 leaves this open. This task decides which, claim
  by claim with listing lines, and proves it by predicting a watched event count from a savestate
  edit.
- **Evidence** (pasted):

    penalty? (Q03.3, Q03.7)" — hypothesis: editing an outfield player's keeping changes no event
    count; editing the keeper's keeping changes saves. Static route: `0791:A10A` (shoot-out) and
    its readers of the player record.
  - F008 (proposed): the player record holds no twelve skills; each is computed from +4, +5, +7 via
    `DS:6DCD` and `DS:6D25` in `DS:6D20..6EB3` (960/960 bars). The screen reads it through
