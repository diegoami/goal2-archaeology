# T13 Savestates as evidence bundles: publish start states to a release, by hash (ADR-008)

- **Kind**: runtime (tooling)
- **Issue**: #37 · **Branch**: `task/T13-savestate-evidence` · **Merge after**: T12
- **Implementer**: opencode (the default chain) · **Claude fallback**: sonnet
- **Reviewer**: opencode (`luna`): medium; never the implementer's family
- **Why**: the start states of E003–E005 live only in git-ignored `scratch/` and `.cache/` folders,
  some of them in worktrees that are removed after a merge. A record names its start state by
  sha256, but nobody can restore that state later. The owner's decision (2026-10-04): savestates
  go to a release of this private repository as evidence bundles, never into the tree (rules 18
  and 20 unchanged).
- **Evidence** (pasted):
  - Rule 20: run records are raw and immutable; evidence bundles are release assets.
  - `tools/verify_evidence.py E<nnn>` (T03) reads `evidence/E<nnn>/*.manifest.json` and checks every
    listed file against release `E<nnn>`: asset name `<sha256[:16]>-<name>`, its sha256. `--local
    <dir>` checks a directory instead. `tools/validate_runs.py` validates `evidence-manifest/1`.
  - The manifest form (`tests/fixtures/evidence/E900/E900-r0001.manifest.json`): `schema`
    `evidence-manifest/1`, `run_id`, `experiment`, `store` `release:E<nnn>`, `artifact` {`set`,
    `variant`}, `files` [{`name`, `bytes`, `sha256`, `asset`, `class` (`save`)}].
  - A run record's `start_state` carries `id` and `sha256` (e.g. E004-r0001: `e004-1000`,
    `e41cffc0…`); its `outputs` is a list (empty in E004).
  - #36: this repository's `verify_evidence.py` is to be replaced by game-archaeologist's pinned
    copy (ADR-009), after game-archaeologist#29. If #36 has merged when this task runs, use the
    pinned tool in Done-when 1 and write no code that depends on the local copy.
  - T07's Done-when 7 keeps `.sav` files out of the tree (one test fixture excepted).
  - The only release today is `goal2-original` (the artifact set); `setup/goal2-runtime.sh`
    downloads it with `gh release download`.
- **Owns**: `tools/publish_evidence.py` (new), `evidence/E005/**`, `tests/test_publish_evidence.py`,
  `runtime/README.md`, `docs/process.md` (one paragraph under its research section, if it has one;
  else `runtime/README.md` only)
- **Scope**: protects the claim that every start state a record names by sha256 can be fetched and
  restored later. `tools/publish_evidence.py E<nnn> --run <run_id> --file <path> [--file …]`:
  computes each file's sha256, uploads it to release `E<nnn>` as `<sha256[:16]>-<name>` (creating
  the release when missing; skipping an asset already there with the same name, after checking its
  sha256), and writes `evidence/E<nnn>/<run_id>.manifest.json` (never over an existing manifest
  with other content). Then publish E005's start states (the T12 worktree's states, kept by the
  main session in `.cache/kept/E005/` before that worktree is removed), one manifest per state, with
  `run_id` the first record that names it. Not in scope: changing run records (immutable), the
  driver's record format, E003/E004 states (their files are gone; recreating them is a separate
  question), per-read savestates.
- **Done when**:
  1. `python3 tools/verify_evidence.py E005` passes against the release, and every `start_state.sha256`
     named by a record in `runs/E005/` is in one of `evidence/E005/*.manifest.json` (a pasted
     command that checks it prints nothing missing).
  2. `python3 tools/validate_runs.py evidence/E005` passes (or the validator's manifest mode, as it
     is invoked).
  3. Re-running the same publish command changes nothing: no new asset, no changed manifest (pasted).
  4. `python3 -m unittest discover -s tests` passes in CI without `gh` access: the tests use a fake
     `gh` and show (a) an asset already present with the right sha256 is not uploaded again, (b) an
     asset present with the wrong sha256 stops the tool with an error and writes no manifest, (c) an
     existing manifest with other content is never overwritten. Each test fails when its check is
     removed (say how you checked).
  5. T07's Done-when 7 command prints nothing (no savestate is tracked).
- **Hazards**:
  - a savestate holds the game's memory: it goes to this private repository's release only, never
    to the tree or a public repository (rule 18);
  - a manifest whose asset was not uploaded: upload first, write the manifest after the upload is
    verified;
  - releases are shared state: never delete or replace an asset; a conflict stops the tool.
