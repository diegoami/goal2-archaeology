# T96 Player attribute dictionary (engine study)

- **Kind**: static research; planning brief under [programme #433](https://github.com/diegoami/goal2-archaeology/issues/433).
- **Issue**: [#435](https://github.com/diegoami/goal2-archaeology/issues/435); **Branch**: `task/T96-engine-study`; **Merge after**: T95.
- **Difficulty**: hard; **Size**: M (2–4 active hours, compute separate); **Complexity**: medium; **Impact**: high.
- **Rating rationale**: Signed bytes and derived skills require evidence reasoning. The dictionary affects lineup decisions and the interpretation of all measurements.
- **Implementer**: main session or the session's selected implementer, using repository tools. **Reviewer**: independent strong-model review for new rule claims; integrated review at ES-R1, then final ES-R5/T113.
- **Review checkpoint**: [ES-R1](../engine-study-reviews.md#es-r1); exact entry, scope and exit criteria apply.
- **Evidence**: T61 attributes.py, image.py, F007/F008/F015/F018/F021/F028 and named/listing readers and writers.
- **Owns**: `docs/engine-study/player-fields.md`, `notes/engine-study/T96/` (source census and supporting evidence). The executable slice fixes exact source/annotation ownership before dispatch.
- **Scope**: Document every player-record field and flag used by the engine, plus its displayed and derived counterparts: name, storage and signedness, legal versus representable range, initialisation, readers, writers and persistence. Trace skill, energy, form, fitness, age, position, foot, status and performance; identify unknown and apparently unused fields explicitly.
- **Acceptance outcomes**: A census ties every player-field access in the selected engine universe to a dictionary row or an explicit unresolved reference. Each row names evidence and distinguishes display, direct match influence, indirect influence and no identified influence.
- **Dispatch gate / Done when**: this brief records scope and expected research results, not executable readiness. Split into independently mergeable, approximately one-hour slices before dispatch; each gets its own issue, ownership and contract. Validate each slice's Done-when commands as failing on pre-task main and passing on a mock fix. Require source/evidence checks, relevant controls and `python3 tools/check_links.py`; ordinary research outcomes above remain mandatory.
- **Hazards**: A display label or comment does not establish semantics. A field with no in-match reader may affect recovery or setup outside the tick loop.

Use the [programme's methods, rating definitions and gates](../engine-study-plan.md).
New measurements have immutable source-pinned receipts; a budget is set before a heavy job.
This package does not select a production backend or silently repair original behaviour.
