- **Why**: every GOAL2 experiment writes run records and evidence bundles, and every finding cites
  them. The research protocol's Done-when lines call these tools by name. `docs/plan.md` G2.
- **Evidence** (pasted):
  - toy-archaeology's tools at its `main` (a3056ff), each a standalone Python 3.11+ script with its
    tests in `tests/`: `ga.py` (fetches game-archaeologist files at the pinned commit with `gh api`
    into `.cache/game-archaeologist/<commit>/`, exposing the checker's `validate`, `semantic_errors`
    and `canonical_set_hash`), `fetch_artifact.py <set-id>` (downloads a set's files from a release
    into `.cache/artifacts/<set-id>/` and verifies each sha256 against `artifacts/known.json`, exit 1
    on any mismatch), `register_artifact.py <dir> --label … --title … --version … --how …` (prints an
    `artifact-set/1` manifest with the canonical id), `validate_runs.py <dir|files>` (validates `run/1`
    and `evidence-manifest/1` with the fetched checker), `verify_evidence.py E<nnn> [--local <dir>]`
    (checks each manifest's files against release `E<nnn>` or a local directory), and
    `check_citations.py <finding.md>` (every run id cited exists; every Answer and Inferences bullet
    cites one).
  - Their toy-specific parts: `RELEASE = "toy-isles-1.0-1.1"` and `TOY_ARCHAEOLOGY_REPO` in
    `fetch_artifact.py`; `TOY_ARCHAEOLOGY_REPO` in `verify_evidence.py`. Here the release is
    `goal2-original`, the repository `diegoami/goal2-archaeology`, and `archaeology.json` pins
    `formats-v1` (33653435545f65c930bdca9bd4f4bd56e79dfa84).
  - Two defects to fix while adapting:
    - toy-archaeology#11: `verify_evidence.py` makes one `gh release view` per manifest and one
      `gh release download` per file (1,783 calls for 1,460 entries in E001) and outran the
      reviewer's limits. One release listing and one download of each distinct asset checks the same
      names and hashes; a bulk download once dropped one file silently, so a missing asset is
      retried or reported by name.
    - toy-archaeology#12: `check_citations.py` reads only a bullet's first line, so a run id on a
      wrapped line is not seen.
  - game-archaeologist#10: a shared validator CLI is due once two game repositories use these tools;
    this is the second. Copy now, with the source noted in each file; extraction is that issue's.
- **Owns**: `tools/**` except `tools/check_links.py`, `tools/harness/**` and `tools/static/**`;
  `tests/**` except `tests/static/**`; `.github/workflows/ci.yml`
- **Scope**:

    repository; each file names its source commit.
  - `verify_evidence.py`: one listing, each distinct asset downloaded once, a missing asset reported

  - CI: fetch the artifact with the workflow's token, then run the tests.
  - **Not in scope**: the driver (G1 and after), static tools (G3), any experiment or finding.
