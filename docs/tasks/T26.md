- **Evidence** (pasted):
  - Backlog Q011: "How are performance ratings and the man of the match computed? (Q03.10, Q09.13)" —
    hypothesis: a rating changes after each tackle, shot and dribble; the MoM has the highest rating.
    Static route: the writers of the performance field; the string `performance` in `DS:4979..4E78`.
  - F008 (proposed): the performance field is the word at +0x12 (bytes +0x12/+0x13) of the 20-byte
    player record at `[A91B]` (layout F007); `1771:3844` reads it (`seg_1771_05.asm:851`),
    `1771:3827` draws the text: blank when 0x7FFF, else a 1..9-character string of
    (+0x12 − 10000 when above 5000) − 0x37, colour 0x0F during a match for slots 1..11 and booked
    players. The main screen's team panel template (`DS:4BBE..4EB1`) carries the `performance`
    label.
  - The `run_match` annotation (established, F005/F009): `0791:F1F6` sets performance 0x37 for
    slots 1..11 before the match.
  - T24's notes (on `main` once PR #78 merges): the goal routine `6443`'s scorer write
    `+0x12 += s8(DS:0x720[ring id])` — a delta table at `DS:0x720` indexed by the commentary event's
    ring id (the quick goal id 0x26 → +40; observed 0x2747 + 0x28 = 0x276F on player 368) — and the
    in-match encoding 0x2747 = 10055 (> 5000 → −10000 → 55 = the initial 0x37).
  - E004's watched-match mechanics (F005): `cycles=30000`, keys only at stopped-clock screens, the
    commentary reader and its event templates (0 substitution, 38 goal, 39 own goal, 50 booking,
    51 sending off, 52 injury); the E010 release's start states for seeded starts.
