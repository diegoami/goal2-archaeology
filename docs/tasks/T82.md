- **Evidence** (from #367): goal2's core (goal2 `goal2/core/runner.py`, `docs/core.md`) starts only from a savestate whose CPU is inside the BIOS INT 16h read that 214B:08DD calls (E006-r0001: F000:CFAA, 08DD's frame on the stack). Every kept state is in the manager menu or at half time; the `title.sav` checkpoints have the CPU at load+214B:1E3E–1E44 and are refused. Leaving the menu for a new game calls INT 10h, which the core does not serve. Needed: (1) a savestate at `title-load-prompt` (or `country-select`) in the read, on the owner's Drive; (2) every interrupt other than the 16h read between that screen and the first manager menu, with call site and what it reads or writes (INT 10h if any; the DOS time read of F004); (3) the key-read sites and caller frames of `title-load-prompt`, `title-player-count`, `country-select-name-entry`, `country-select`, if cheap. Then an issue in goal2 (§14).
