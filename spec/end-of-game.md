# Sacking and the end of the game

Written by the main session at promotion (docs/wide-pass.md, the wide pass of 2026-10-13): rows drafted from reviewed findings F001-F022 by read-only agents, statuses re-derived by the main session (`corroborated` only with two findings and both a behavioural and a static method in the Basis and Findings cells). The summary describes only `supported` and `corroborated` claims.

## Summary

Established: this release is the registered build that saves (C-END-02: F7 and F10 write `SAVED.GL`), so the shareware one-cycle limit is not met by the files here. The 4-year cycle is a stage counter that wraps into 2..8 (C-END-04), so play does not stop in the code read. The executable carries dismissal text and a routine that releases a human's country (C-END-03, C-END-06). The criterion for dismissal and the performance measure are not found (C-END-05).
