# Customisation (ALTER.EXE)

Written by the main session at promotion (docs/wide-pass.md, the wide pass of 2026-10-13): rows drafted from reviewed findings F001-F022 by read-only agents, statuses re-derived by the main session (`corroborated` only with two findings and both a behavioural and a static method in the Basis and Findings cells). The summary describes only `supported` and `corroborated` claims.

## Summary

Established: `ALTER.EXE` exists, is LZEXE 0.91 and unpacks with the project's tool; it shares strings and code units with `GOAL.EXE` and names `goal.dat` (C-ALT-01, C-ALT-02). The data it can change follows from the help file together with the representation: names (R002-R006), colours (R007) and rankings (R009, R010) are in `GOAL.DAT`, and no skill is, so it cannot set a skill but it does change every player's strength by the ranking route (C-ALT-04, C-ALT-05). Nothing of ALTER's own code or screens has been read.
