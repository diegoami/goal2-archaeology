# Knowledge map

What is known about each area of *goal (version 2)* (artifact set `goal2-a949da2f`), and how it is
known. **Everything starts `unknown`.** A cell moves only by evidence: to `documented` when G4 records
a help-file passage as a source (basis `doc`), and beyond that only through a reviewed finding and its
promotion into `spec/`. Statuses and basis tags follow game-archaeologist's `vocabulary/` at the
commit [`archaeology.json`](archaeology.json) pins.

The Source column names the `GOAL.HLP` lines (in the released file, CR LF stripped) that describe each
area. It is a pointer for G4, not yet a `documented` claim.
