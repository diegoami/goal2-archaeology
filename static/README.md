# static/

Derived extracts that U17 allows here, never the original files: the unpacked executable's listings, decompiled routines, data-file tables. Each extract names the artifact file and its sha256, the tool and its version, and the offsets it covers. Static findings cite them by path and offset.

Contents (all regenerated by `tools/static/regenerate.sh`, except the map, which is written by hand):
- [`goal-exe/`](goal-exe/README.md): the listing of the unpacked `GOAL.EXE`, its routine, call, data-reference and string tables.
- [`goal-exe-map.md`](goal-exe-map.md): an index of that code by the areas of `knowledge-map.md`, each entry marked observed or inferred.
- `goal-dat/`: the block table of `GOAL.DAT` and the checks of finding F002's representation claims.
